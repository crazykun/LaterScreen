# LaterScreen v0.1.0 —— 首个发布版 🎉

跨平台截图标注工具，Rust 编写。单文件、约 3~4MB、无动态库依赖、启动即用。
一个 `lscreen` 命令，覆盖截图、标注、取色、二维码、OCR、GIF 录屏。

## ✨ 亮点

- **交互截图**：拖拽框选（带像素放大镜取景），选区支持角点/边缘拖拽缩放、
  整体移动、宽×高精确输入
- **9 种标注工具**：矩形、椭圆、箭头、画笔、自增标号、文本（支持中文输入法）、
  马赛克、橡皮擦（恢复原图）、选择编辑，全量撤销/重做
- **屏幕取色器**：像素级放大镜，一键复制 RGB / HEX / CMYK
- **识别能力**：选区内二维码识别、OCR 文字识别（Linux，需 tesseract）
- **GIF 录屏**：`lscreen record`，gifski 纯 Rust 编码
- **CLI 无界面模式**：`shot` / `record` / `qr` / `ocr` / `pick` 子命令直达，
  适合脚本与全局快捷键绑定

## 🚀 快速上手

```bash
lscreen              # 交互截图：框选 → 标注 → Ctrl+C 复制 / Ctrl+S 保存
lscreen pick         # 屏幕取色，单击复制 HEX
lscreen qr           # 识别屏幕上的二维码
lscreen shot --region 100,100,800,600 -o out.png   # 无界面截图
```

全局唤起：在系统快捷键设置中绑定 `lscreen` 命令即可。

## ⚠️ 已知限制

- **Linux 仅支持 X11**：Wayland 会话暂不可用（xdg-desktop-portal 支持规划中）
- **macOS 应用未签名**：首次打开需右键 →「打开」，或
  `xattr -d com.apple.quarantine /Applications/LaterScreen.app`；
  首次截图需在「隐私与安全性 → 屏幕录制」中授权
- **OCR 目前仅 Linux**（依赖系统 tesseract：`sudo apt install tesseract-ocr
  tesseract-ocr-chi-sim`）；Windows / macOS 原生 OCR 规划中
- Windows / macOS 为首个构建版本，欢迎反馈问题
