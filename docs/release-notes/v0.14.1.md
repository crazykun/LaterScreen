本版主题是**设置面板交互与视觉重做**：右侧六个分区改为一个连续滚动页，滚动自动联动左侧导航高亮、点击导航跳转到对应分区；整体配色转现代扁平风；按用户偏好把 v0.14 换成的品牌蓝改回红色系。

## 🧭 设置面板：连续滚动 + 双向联动导航

- **连续滚动页**：右侧内容不再按页签切换，通用/截图/录屏/文字识别/热键/关于六个分区在同一滚动页里从上到下排布，上下文连贯、不再一页一跳。
- **滚动侦测（scroll-spy）**：滚动时左侧导航自动高亮当前分区；滚到最底自动选中「关于」（矮分区碰不到判定线的兜底）。
- **点击导航跳转**：点击左侧任意分区，右侧瞬时滚动到该分区起点；跳转帧跳过侦测，高亮不会闪回旧分区。
- **进门不再弹提示**：打开设置时的 PP-OCR 模型自动探测改为静音，结果只落在卡片状态里；只有手动「检查 / 下载 / 校验」才有完成 toast。此前每次打开都弹「检查完成：PP-OCR 模型已就绪」属噪音。

## 🎨 扁平化视觉

- **去边框堆叠**：卡片、输入框、按钮、下拉框全部去掉 1px 描边，轮廓靠底色色调分层 + 大圆角（卡片 12px）表达，浅色主题为「浅灰页面 + 纯白卡片」。
- **输入框**：空闲态纯填充无边框，聚焦才出现强调色描边环；热键录入态保留强调环（「正在监听键盘」的焦点语义）。
- **导航选中态**：由实心色块改为品牌色淡 tint 底 + 左侧指示条 + 主题化前景色，未选中悬停为浅灰。
- **品牌色改回红**：v0.14 的品牌蓝按用户偏好改回 LaterScreen 红 `#e53935`，选中态、强调前景/描边、按钮填充等全套派生色同步恢复红色系，对比度（WCAG AA）回归测试全部保持通过；默认标注色随之回到红色。

## 🛠 修复

- **模型下载抗瞬断**：PP-OCR 模型下载对传输层瞬时错误（连接被重置、本机栈中止等）自动重试一次（重新连接、半成品自动清理，超时类不重试以免翻倍等待）。此修复同时消除了 Windows CI 上本地回环测试服务器的偶发连接中断导致的测试失败。
- 测试服务器改为按请求路径路由响应，传输层重试不会错位拿到其他文件的响应；命中数断言允许重试翻倍。
