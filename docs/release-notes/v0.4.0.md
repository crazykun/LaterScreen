本版本交付两大录制能力：MP4 录屏与滚动长截图，并补齐 Wayland 整屏截图、窗口截图与全新应用图标。

## 新功能

**🎬 MP4 录屏（Linux）**
- `lscreen record --mp4`：H.264/MP4 编码，openh264 静态链接（vendored C++ 源码，无动态库依赖），`mp4` crate 封装（AnnexB→AVCC、SPS/PPS→avcC）
- `--quality` 在 MP4 模式下为目标码率 kbps（200-50000，缺省 4000）；GIF 模式仍为质量 1-100（缺省 90）
- 真机验证：ffprobe 读回 h264/Constrained Baseline、时长帧数正确、ffmpeg 可解码；失败路径与 GIF 同语义（清半成品、join 编码线程）

**📜 滚动长截图（Linux X11）**
- `lscreen scroll`（托盘菜单「滚动截图」同入口）：框选区域 → 自动滚动 → 帧间拼接为长图
- XTest 合成滚轮事件驱动窗口滚动，指针自动移到区域中心、结束恢复原位
- 尾部块两阶段匹配拼接：签名行预筛候选 + 整块 SAD 校验，容忍抗锯齿/渲染噪声；滚到底（连续 2 帧无新增）或内容突变（悬浮表头等）自动停止并保留已拼部分
- 收尾进入**标注预览窗口**：完整标注工具栏（矩形/箭头/文本/马赛克…），Ctrl+滚轮缩放（锚定指针）、Ctrl+0 适应宽度、中键拖动平移；超大长图纹理自动降采样显示（保存/复制仍全分辨率）
- 显式 `-o` 直存 PNG（脚本用法）

**🖥 窗口截图（M9）**
- 截图覆盖层悬停自动吸附窗口选区；可配置初始选区 = 最前窗口/全屏/无
- 窗口枚举走 EWMH，按 Z 序排序，面板/桌面/菜单等不参与吸附

**🌊 Wayland 整屏截图**
- 纯 Wayland 会话下 `capture_primary/at/all` 走 xdg-desktop-portal（ashpd 纯 D-Bus，无 pipewire C 库依赖）
- 区域采帧/录屏/指针控制在 Wayland 下明确报错降级（仍需 X11）

**🎨 全新应用图标**
- 全新彩色描边风格图标，统一应用于：托盘、窗口（`_NET_WM_ICON`）、任务栏、deb/rpm/AppImage 桌面入口、Windows exe 资源、macOS .app、官网 favicon

## 修复

- **Linux 任务栏图标归属**：egui 的 `with_app_id` 在 X11 下不生效导致 WM_CLASS 缺失，任务栏匹配不到 .desktop 显示错误图标；现窗口创建时显式写 `WM_CLASS=lscreen` + `_NET_WM_ICON`，desktop 文件补 `StartupWMClass`
- **MP4 封装正确性**：AnnexB 切分不再把下一起始码算进 NAL（污染 avcC/样本数据）
- **滚动拼接采样覆盖**：帧签名按 4px 跨步覆盖整行宽度（此前只看左 1/4，右侧悬浮元素不触发停止）
- **滚动截图错误路径**：出错时状态窗口正常自动关闭、指针恢复原位
- **录屏工具栏溢出**：预览窗口最小宽度提升，工具栏过窄时靠左钳住
