本版本交付 M11 截图历史（Snipaste 式缩略图面板）与 M10 录制体验（选区边框、armed 待开始、格式配置），全局热键扩展到全部六个动作，并消除 Windows 驻留时的 cmd 黑框。

## 新功能

**🗂 截图历史面板（M11）**
- 托盘「历史」或独立历史热键打开 Snipaste 式缩略图浮窗，列出最近的截图/贴图/录屏：固定高缩略图、鼠标拖拽滚动、面板贴近托盘并定位主屏
- 单击缩略图=复制（带反馈），录屏条目点击直接用默认播放器播放；右键贴图/打开目录/删除
- 顶栏显示条数与占用体积，支持一键清空；面板单实例，已在后台时再按热键唤到前台
- 副本存平台缓存目录（`~/.cache/lscreen` / `%LOCALAPPDATA%` / `~/Library/Caches`），可随时整目录删除不影响配置
- 覆盖所有产出点：截图保存、贴图创建/保存、CLI `shot`、`scroll -o`、录屏落盘（另存首帧 poster，source 指向实际 GIF/MP4）
- 可配置历史条数（默认 10，1-50）、复制后自动关闭；托盘「最近」子菜单带缩略图图标并轮询刷新

**🎥 录制体验（M10）**
- 录制期间选区外侧常显边框（红蓝闪烁，不进成品帧）
- 录制不再立即开始：先进 armed 待开始状态，Enter 确认、Esc 取消
- 录制格式（GIF/MP4）进配置；状态窗自动避开选区，头部 UI 交互与视觉重做（拖拽区与齿轮点击区分离）

**⌨️ 全局热键扩展**
- 热键覆盖全部六个动作：截图/取色/贴图/录屏/滚动截图/历史；录屏与滚动截图为新增，默认留空不注册

**🔍 识别结果面板**
- OCR 结果面板可拖动、可缩放；复制按钮移到顶栏，长文本不必滚到底

**⚙️ 设置面板**
- 保存目录旁新增「打开目录」入口，直达文件管理器

## 修复

- **Windows cmd 黑框**：主程序与安装器改 GUI 子系统，双击/快捷方式/托盘 spawn/安装完成页「运行」都不再带出控制台窗口
- **安装器**：强制暗色主题 + 底部固定按钮条，修复按钮/浏览出界
- **MP4 奇数尺寸**：宽高裁偶防 openh264 崩溃
- **托盘卡死**：历史条目后台执行，移除 `menu_about_to_show` 同步刷新
- **历史面板 UI**：滚动条贴右缘、列表项 12px 间距红框不压行、缩略图吃满行宽、录屏点击真正播放
