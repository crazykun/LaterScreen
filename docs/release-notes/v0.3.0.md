本版本重点打磨托盘常驻形态的配置体验：设置窗口全新视觉、热键可视化录入，并修复独立窗口的中文乱码与面板布局问题。

## 新功能

**🎨 自定义暗色主题**
- 设置窗口整体改为自绘暗色视觉：深灰底 + 分区卡片 + 品牌红强调色，控件圆角、悬浮态、选中态逐一定制
- 卡片式分区（带强调色小竖条），配置项分组清晰

**⌨ 热键可视化捕获**
- 热键字段点击进入录制态，直接按键录入（如 `Ctrl+Alt+A`），无需手敲字符串
- 录屏态吃掉全部按键事件：Esc 取消保留原值，Backspace/Delete 清空绑定
- 裸键（无修饰键）仍仅允许 PrintScreen / F1-F12，录入非法组合就地提示不落盘

## 修复

- **独立窗口中文乱码**：录屏状态窗口、设置窗口现在各自挂载系统 CJK 字体（内置字体无中文字形，此前显示为方块）
- **设置窗口面板高度自增**：底部面板固定 48px，修复 `Panel::bottom` 高度计算错误导致表单被顶出/消失的问题

## 其他

- 配置面板校验逻辑完善：保存前对模板/热键/颜色/工具名全量校验，非法字段就地提示（不落盘）
