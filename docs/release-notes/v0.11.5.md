本版本按用户实测反馈修双击复制、把主复制按钮改成纯图标绿色对号，并合并 macOS 平台的两项修复（窗口枚举重写、轻点抖动按单击处理）。

## 修复：双击复制在真机上不生效

- **双击判定不再依赖 egui 的 `Response::double_clicked()`**（用户主诉「Deepin 上双击不管用」）。egui 内置的判定挂在 `InputState::last_click_time` 上，而该时间戳只在「释放被判为 click」时更新——click 又受 `max_click_duration`（按下超过 0.8s 不算 click）与 `max_click_dist`（按下期间位移超过 6px）夹逼，任一条件不满足第二击就拿不到事件，表现为时灵时不灵。现在每次左键**释放**自己打时间戳（`SnipApp::last_click`），双击 = 与上次释放间隔 < 0.35s 且落点相距 ≤ 8pt；只看两次释放之间的关系，与按下时长和按下期间的抖动无关。
- **双击不再要求落在选区内**（用户反馈「只有双击截图里面的区域才行，点外面的空白区域不行」）。选区外的暗化区同样属于画布，双击它就该交付——尤其框选窗口时选区紧贴内容、边界外只有几十像素可点。旧逻辑把 `inside_region` 作为复制的必要条件，这条限制已删除；命中图元、已有选中、非选择工具时仍让位给各自的语义（文本编辑、连续放置、拖拽移动）。
- 阈值本身由单测锁住（`cargo test -p lscreen canvas`）：`double_click_thresholds_are_human_paced` 卡住 0.25–0.4s 的时间窗与 6–16pt 的位移容差，避免放宽到「两次普通单击也算双击」。

## 修复（macOS）：窗口枚举重写 + 轻点抖动按单击处理

- **窗口枚举改为单次 `CGWindowListCopyWindowInfo` 扫描、直连 CFDictionary 读取**。xcap 0.9.8 的 mac `Window` 每个字段访问器（x/y/width/height/title/app_name…）都各自重新全量扫一遍窗口列表，上层逐字段读取即 N 窗口 × ~10 次全量枚举，GUI 启动还要 list_windows + frontmost_window 各来一轮——真机（21 窗口）实测旧路径单轮 513–716ms，重写后稳定 2–3ms，是 mac 截图入场延迟的大头。
- **只保留普通层（layer 0）应用窗口**：Dock 进程持有整屏大小的底窗且 Z 序在应用窗口之上，不过滤会把悬停命中、单击选窗与「最前窗口」初始预选全部吞成全屏；菜单栏/状态项同理不再入吸附列表。另外 `kCGWindowName` 缺失（无「屏幕录制」授权）时窗口保留、仅标题留空，窗口吸附不再依赖授权状态（xcap 会把这类窗口整条丢弃）。
- **轻点抖动视为单击**：egui 指针位移超过拖动阈值（约 6px）即判拖拽，触控板快速点按常带同量级抖动——手势落在 drag_stopped 且矩形小于最小选区（4×4）时原先被静默吞掉，表现为「点了窗口却没选上」。现按单击语义重新走选窗/全屏逻辑（拖拽期间悬停命中是关闭的，此时重新取悬停窗口）。

## 变更：主复制按钮改为纯图标绿色对号

- 截图工具栏最右的交付按钮去掉「复制」二字，只剩对号图标，尺寸从 76×32 收成 32×32 的正方形，与左侧一组灰色线性图标（保存/上传/贴图/识别/生成）在视觉权重上一眼分层，也和「全图标常驻、语义靠 hover 文案承载」的工具栏契约一致。语义不变：单击即复制到剪贴板并退出。
- **绿色走令牌而非硬编码**：新增 `theme::SUCCESS_FILL` = `#2e7d32`（Material Green 800）与 `theme::SUCCESS_ON_TEXT`（白）。调色板里的绿 `#43a047` 配白字只有 3.30:1，不到 WCAG AA 的 4.5:1——与品牌红同因，中间亮度的色承载白字都要压深一档。悬停态是它的 `gamma_multiply(0.92)`（压深而非提亮，白字对比度 5.13 → 5.85），都由新增单测 `theme::success_fill_carries_white_text` 锁住。对号图形本身仍跟随调用方传色（贴图条上的对号继续用普通前景色，此处改的是截图覆盖层那一处）。

## 已知事项

- Deepin 25（X11）真机点验：新二进制在选区外（1400,200）双击 3/3 复制成功、旧二进制 0/3；选区内两者在 0.28s 释放间隔下新二进制成功、旧二进制失败（间隔再放宽到 0.30s 两者都不触发，符合 0.35s 阈值）；工具栏最右按钮实测渲染为 `#2e7d32`、hover 文案为「复制到剪贴板并退出 (双击画布 / Ctrl+C / Enter)」。
- **macOS 升级后 TCC 授权会重新弹窗**：产物未做代码签名，macOS 按二进制内容识别应用，每次升级（brew upgrade / 换装 dmg）都被当作新应用，「屏幕录制 / 麦克风」授权失效。处理步骤见 README「安装」节：完全退出 lscreen → 系统设置删旧条目 → 重启触发授权 → **授权后再重启一次**（常驻进程只在启动时读取授权）。
- 自动化验证注意：真机测试前先确认桌面未锁屏（`xdotool getmouselocation --shell` 的 WINDOW 是 `org.deepin.dde.lock` 时键盘与指针事件全部被吞，连 Esc/Ctrl+C 都无效，结果不可信）。
- 双击是画布手势，工具栏按钮与 Ctrl+C / Enter 的行为不变。
