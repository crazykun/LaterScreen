本版本主题「三平台能力对齐」：滚动长截图与范围提示红框补齐到 Windows 和 macOS，并修复 macOS 高分屏（Retina）选区偏移。Linux 行为不变。

## 新功能

**Windows / macOS：滚动长截图**

此前这两个平台无法向目标窗口注入滚轮事件，框选完成后会按 v0.7.0 的兜底逻辑退化为一张普通区域截图。现在 Windows 经 SendInput、macOS 经 CGEvent 合成滚轮并自动接管指针，与 Linux 全流程一致：框选 → 自动滚动 → 帧间拼接长图 → 标注预览。

注意（Windows）：目标窗口以管理员权限运行时，系统 UIPI 会拦截来自普通权限进程的事件注入，此时保持原有降级行为（当普通截图处理），不会报错。

**Windows / macOS：录屏与滚动截图的范围红框**

- 录制进行中，选区外围有一圈**红蓝交替闪烁**的边框，提示「正在录这一块」；滚动截图期间则是恒定红框。
- 边框绘制在选区**外侧**，贴屏幕边缘时宁缺一边也不越界——从结构上保证边框永远不会出现在录制的视频画面里。
- 此前 Windows / macOS 录屏看不到任何范围提示，只能凭记忆确认录的是哪块。

## 修复

**macOS：高分屏（Retina）区域截图截错位置**

屏幕采集拿到的是物理像素（2x 缩放的原始分辨率），而选区坐标是逻辑点，此前两套坐标直接混用：选区与成片存在整体偏移，外接屏上更严重。现在统一按所在显示器的缩放比换算。多显示器混合 DPI 的组合仍是近似处理。

## 工程

- CI 恢复全绿：v0.7.1 引入的历史模块测试会写真实缓存目录，在全新的 CI 环境必然失败（自 v0.7.1 起 CI 一直红）。测试已改走临时目录，不再依赖、也不再污染运行机器上的用户数据
- 发布矩阵瘦身：砍掉 armv7 / i686 架构与 rpm 格式（近 5 个版本 0 下载），每个版本的 Release 附件从 23 个减到 13 个，构建 job 从 7 个减到 5 个
