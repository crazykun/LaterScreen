本版主题：**mac 所有 GUI 窗口统一为菜单栏应用形态（Dock 图标全隐）**，新增**历史窗口热键/菜单 toggle** 与**贴图「隐藏外层」纯图模式**，并补齐安装器开机自启与托盘退出联动关闭。

## ✨ 变化

- **mac Dock 图标全隐**：截图/贴图/历史/设置等所有 GUI 子进程统一声明为 Accessory（菜单栏应用）形态——不再占 Dock、不进 Cmd+Tab（此前贴图、历史会各挂一个 Dock 图标）。`Info.plist` 增加 `LSUIElement`，运行期经 winit `event_loop_builder` 显式声明，避免裸跑二进制被系统改回 Regular。原先给子进程补设 Dock 图标的 `set_dock_icon` FFI 整段移除。
- **历史窗口 toggle**：热键/菜单第一次按出窗、再按收起（已有面板时改为发送退出信号而非唤起，quit 优先于 raise，不会先跳前台再关）。
- **贴图「隐藏外层」纯图模式**：工具条新增眼睛按钮，点击后只显示图片（隐藏边框/工具条/OCR 面板），**鼠标移入窗口时浮出工具条**、移出即隐，再点恢复。窗口 = 图像当前显示尺寸，宽度保底工具条所需下限；纯图期间缩放窗口跟随，点 OCR 自动恢复完整布局。

## 🛠 修复与完善

- **安装器支持开机自启**（HKCU Run，默认勾选，卸载按值名清理）；覆盖安装前 taskkill 结束 lscreen 进程并短重试等待映像锁释放；安装器暗色主题描边/输入框底色与主程序一致。
- **托盘退出时联动关闭**历史面板、配置面板与全部贴图（独立进程不会自动跟随托盘退出，改为留退出信号/广播）。
- instance 单例测试修复：测试前释放已持锁，修 CI 上清信号分支覆盖不到的问题。
