本版主题是**贴图与 OCR 结果合体为一个窗口**，并修复 mac 上一批贴图/标注交互问题：面板与窗口拖动、工具栏居中、编辑接力落点、标注窗与 F1 截图窗分离，以及滚动截图的辅助功能权限预检。

## ✨ 变化

- **OCR 结果并入贴图右侧面板**：识别成功不再弹出独立结果窗口，而是「贴图 + 识别结果面板」合体窗，原文对照、随贴图移动。从贴图点「编辑」进标注窗后再点 OCR，会在**原贴图位置**重新开出合体窗（含标注）；点「贴图」按钮回贴图时落点同样与原贴图一致，不再跑到屏幕左上角。
- **贴图固定框缩放**：放大/缩小只改变图像，窗口外框尺寸不变。
- **贴图拖动边界明确**：除 OCR 正文文字区（拖动 = 选中文字）外，图像、面板标题、留白、卡片边框、工具条空白都可拖动移动窗口。
- **F1 启动更稳**：800ms 启动节流 + 恢复覆盖层单例，连按不再成群弹窗；托盘启动时隐形预热（预载 AppKit/GL/字体页缓存），首次按 F1 不再冷读盘。

## 🛠 修复（mac）

- **标注窗与 F1 截图窗分离**：标注窗不再持有 Overlay 单例锁——此前标注窗开着时按 F1 会静默退出，看着像「没反应」。标注窗标注的是已有图片，本就不需要「干净屏幕像素」。
- **标注窗底部工具栏按内容宽度居中**，不再贴窗口左边框；窄窗口仍保持单行不换行。
- **OCR 面板拖不动窗口**：根因是独立 layer 的 `egui::Area` 在命中搜索里阻断下层（`movable(false)`、`Label selectable(false)` 都绕不开），面板改为根 Ui 内绝对定位子 Ui 后根治，附回归测试。
- **框选精简条提示文案与按钮同一中线**：行高钉成按钮槽位高（须在 `horizontal` 之前设置，否则初始行高已取定）。
- **滚动截图前预检「辅助功能」权限**：此前未授权时 `CGEventPost` 注入的滚轮被系统静默丢弃，表现为「滚动截图完全不动」且不报错；现在启动即检测并打开系统设置。
- 覆盖层交付淡出（约 120ms），消除全屏遮罩瞬间消失的闪动；工具条槽位底色分层、标号数字圆内居中、文字标注 WYSIWYG 等一批观感修正。
