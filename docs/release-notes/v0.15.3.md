本版主题：**修复 macOS 浏览器里滚动截图「在页面顶部一下滚到最后 / 拼出重影或只有一屏 / 顶部滚不动」**。真机定量复现后定位到根因在滚轮事件注入，而非拼接算法。

## 🐞 根因

`CGEventCreateScrollWheelEvent` 是 C 变参函数；Rust 侧传入 `-1` 时，arm64 上创建出的事件增量字段被截成低字节 `255`（同一时刻 C 程序创建的同一事件是 `-1`）。浏览器按「向下滚 255 行」处理，因此即使一格一格注入，页面也会直接冲到底部；几乎零重叠的两帧又被拼接器误判为可拼接，产出长图内容回跳、重影（Intel 机器验证时未暴露，Apple Silicon 上才现形）。

## ✨ 变化

- **滚轮事件显式写增量字段**：不再经 C 变参传增量，改用 `CGEventSetIntegerValueField` 覆写 `DeltaAxis1 / FixedPtDeltaAxis1 / PointDeltaAxis1`；行单位每格 1 行（Edge 实测 **40px/格、整像素对齐**），事件之间留 10ms 防止连发被整批吞掉。
- **采帧改「先等滚动起步、再等动画收尾」**：指针移动后首个滚轮事件常被系统吞掉，旧逻辑固定等待后连拍两帧没差异就判「没滚动」，在页面顶部直接退化成普通截图；现在未拼上内容前给 4 次耐心。
- **拼接器加重叠下限守卫**：单步位移超过「帧高 − 匹配块」时按内容突变停止并保留已拼好的部分，绝不把错位内容拼进长图（附回归单测）。
- `--clicks` 默认 2 → 8：单格位移从约 408px 回到 40px 后，原上限会让吞吐掉一个数量级；实际每步格数仍由首步实测位移闭环校准。

## ✅ 真机验证

Edge 测试页从页面最顶部起拍，选区 1050×440、连续 20 步：首步 40px，其后每步精确 200px；页面实际滚动 3840px，长图 4280px（= 440 + 40 + 19×200）完全对账，接缝处行号连续，无重影、无回跳。`cargo fmt` / `clippy -D warnings` / `cargo test --workspace` 全绿。
