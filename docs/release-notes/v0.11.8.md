本版本为 macOS 真机点验 + 滚动截图体验修复合集，共六项（四修 mac 桌面体验，两修滚动截图流程），全部经真机验证。

## macOS 修复

- **窗口吸附/初始预选缩成「左上角小窗」**：GPU 缩放模式（如 2880×1800 面板跑"看起来 1440×900"）下，窗口枚举的缩放比计算用了 `CGDisplayPixelsWide`——它在 GPU 缩放模式下返回逻辑宽而非物理宽，算出 scale=1，窗口矩形全部留在逻辑坐标：初始预选、悬停吸附、单击选窗只有应有大小的 1/4 且钉在左上角。改用 `CGDisplayModeGetPixelWidth` 与截屏位图同口径。同时修正打包 .app 的自家窗口过滤（系统上报的窗口 owner 名是应用名 LaterScreen 而非可执行文件名 lscreen，设置/历史面板曾漏进吸附列表）。
- **延时截图倒计时窗黑字不可见**：倒计时窗硬编码深色底且从未装载主题，egui 跟随系统外观时浅色模式下按钮文字为黑色，压深底完全看不见。现与设置/历史窗同一主题入口，全令牌取色，取消按钮改实心红+白字，深浅主题下均达 WCAG AA（新增对比度回归单测锁定）。
- **历史面板/贴图等托盘子进程 Dock 图标错误**：托盘动作都是独立子进程，裸可执行文件不经 LaunchServices 启动，Dock 显示系统默认图标而非应用图标。现于窗口首帧经 `NSApp setApplicationIconImage` 补设内置打包图标（真机实验确认：更早的时机设了 Dock 也不采纳）。零新依赖。
- **历史面板进程图标归属**：随窗口枚举修复一并生效。

## 滚动截图 / 录屏

- **框选后可移动调整选区**：此前画完框立即交付开始采集，框画错只能 Esc 重来。现改为两阶段：画框后进入调整阶段——拖选区内部整体移动、拖角/边改大小，Enter / 双击 / 绿色对号确认交付，Esc / 红色叉取消。录屏 `--select` 与滚动截图共用此流程，一并生效。
- **预览标注窗工具栏不再折行**：折行阈值是 32px 按钮时代的旧值，按钮缩小后 900pt 宽的预览窗差几个点就被判成窄屏折成两行；阈值下调后单行放下。
