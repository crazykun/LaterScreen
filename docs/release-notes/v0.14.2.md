本版主题是**暗色主题的可读性与选中态修正**：v0.14.1 的全面扁平化在浅色主题成立，但暗色明度范围小，纯色调分层让控件糊成一团——暗色恢复控件描边；暗色选中态由发闷的暗砖红改为中性高光。

## 🌙 暗色主题修正（浅色维持 v0.14.1 扁平样式不变）

- **控件轮廓**：暗色下输入框 / 下拉框 / 按钮恢复一条与卡片拉开差距的描边（浅色仍是无边框纯色调分层——两种主题各自采用在该明度范围下成立的策略）；输入域底色同时提亮一档，双层可辨。此前暗色下 select 和 input 边框几乎不可见。
- **选中态换色**：暗色的选中底（文本选区 / 下拉展开 / 滑块已走过区段 / 可点列表选中项）由压暗的砖红 #6b2622 改为**中性提亮灰** #303038——压暗的红在暗底上发闷发棕；选中文字与聚焦环改为提亮珊瑚红 #ff8a80，红色识别度更高且对比达 AA。
- **左侧导航选中项**：暗色下由红色 tint 改为中性高光块 + 珊瑚红文字 + 品牌红指示条，与全局选中语言一致。

对比度（WCAG AA）回归测试全部按新契约更新并通过。
