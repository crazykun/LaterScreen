本版本主题「历史面板放对地方」：修复截图历史面板在三个平台上的位置错乱，并让它记住你上次摆放的位置。

## 修复

**历史面板位置三平台错乱**

旧版打开历史面板时，把屏幕采集层拿到的**物理像素**坐标直接交给窗口系统，而后者按**逻辑坐标**解释，两套单位在高分屏上并不相等：

- **Windows**：125% / 150% 显示缩放下坐标被放大 1.25~1.5 倍，面板直接飞出屏幕边缘或被窗口管理器钳到奇怪的位置；100% 缩放时碰巧正常，最难以排查
- **macOS**：Retina 屏与外接屏混用时坐标系不一致，菜单栏下方的预留高度也不准
- **Linux（Deepin 等）**：坐标数值正确，但默认贴屏幕底部 8px，正好压在 dock / 任务栏上

现在定位改为窗口首帧用 egui 逻辑坐标下发（按所在显示器缩放比换算），三个平台自洽；默认摆放也避开系统栏——macOS 贴主屏右上角、菜单栏下方，Windows / Linux 贴右下角、任务栏上方。

## 新功能

**历史面板记住上次位置**

面板拖到哪儿，下次打开就在哪儿（Snipaste 同款体验）。位置记忆持久化在缓存目录，且恢复前会校验仍然落在当前桌面范围内——拔掉副屏、更改分辨率后自动回退默认摆放，不会出现「面板打开即消失在屏幕外」。

## 升级提示

- 从托盘菜单或应用程序列表启动的用户：升级 deb / 安装包后请**重启托盘**（退出托盘再启动一次），旧托盘进程指向的二进制已被替换，直接点菜单可能没有反应
