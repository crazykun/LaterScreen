## 修复：工具栏恢复全图标常驻（撤销 PR #1 的「更多」收纳菜单）

- **贴图工具条不再收纳进「更多」菜单**（用户反馈三连：菜单里是中文文字不是图标、竖排展开影响操作、穿透按钮被收进菜单后无法取消穿透）：此前窄贴图会把穿透/旋转/保存等按钮收进一个竖排文字菜单，开启点击穿透后该菜单锚在穿透窗口里点不开——菜单项不在 XShape 保留的输入条带内，点击直接穿到下层窗口，只剩 Esc/托盘两条暗道能恢复。现在十个图标全部常驻条带（置顶/穿透/旋转/水平翻转/垂直翻转/缩放 −%+/保存/关闭/复制），悬停即出文字提示；垂直翻转从「只藏在菜单里」升级为独立图标按钮。
- **贴图窗口宽度保底 320pt**：窄图（如 40px 小图标）此前会把穿透按钮挤出条带形成死锁，现在建窗/缩放/旋转变换三条路径的窗口宽都不低于工具条全量图标宽度，穿透按钮永远可点。
- **截图工具栏同步去菜单化**：交付动作（保存/上传/贴图/识别二维码/识别文字）恢复为图标常驻，窄窗口折行而不是收进文字菜单；被合并吞掉的「生成二维码」图标入口恢复（识别图标 + 右上角「+」角标，点击弹出输入浮层）。
- 顺带修掉两处配色问题：主复制按钮的绿色对号改为跟随调用方传色（绿勾画在品牌红实心底上只有 1.79:1，且红绿色弱不可辨，现改白勾）；复制按钮悬停从「提亮」反转为「压深」（提亮会让白字对比度跌破可读线 4.5:1，压深则升到 5.65:1）。

## 新功能：全应用交互窗口单例

- **截图/取色/框选覆盖层同一时间只允许一个**（`gui`、`gui --delay`、`pick`、`record --select`、`scroll` 框选、滚动拼接预览 `annotate`）：此前热键连按会叠出两层全屏覆盖层，第二层截屏时把第一层截进图里；延时截图期间连按还会把倒计时窗截进去。冲突时第二实例静默让路（第一层交互本来就在最前）。
- **配置面板单例**：连开两个配置窗会各写各的 config.toml、后保存的覆盖先保存的；现在第二次启动会把已开的窗口唤起到前台后退出。
- **托盘单例**：双开托盘此前会出现两个托盘图标外加一串「热键注册失败」（热键已被第一个实例占住，第二个却照常驻留）；现在第二个实例提示已驻留后直接退出。
- 锁实现复用历史面板已验证的 flock/LockFileEx 句柄锁语义：进程退出（含崩溃）自动释放，不留 stale 锁；锁文件在缓存目录 `singleton.{tray,settings,overlay}.lock`。**贴图刻意保持多开**——一屏多钉是 Snipaste 式核心用法；`shot`/`qr`/`ocr` 等无界面命令不受影响。
