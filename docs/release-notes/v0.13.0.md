本版主题是**日常体验打磨**：OCR 识别质量与结果窗口、贴图编辑接力、全局字重修复（浅色主题发白的真正根因），以及 Wayland 窗口装饰与工具栏布局的一批修正。

## 🔤 全局字体修复（浅色主题发白的真正根因）

- **字重修复**：`fc-list :lang=zh` 在部分系统把 `NotoSansCJK-Thin` 排在 `Regular` 之前，旧评分同分取先出现，导致整个应用（含标注导出）用极细字重渲染——夜间白字显粗看不出，浅色主题暴露「又白又轻」。现细字重（Thin/Light/DemiLight）重罚、Medium 优先，系统无 Medium 时退 Regular。
- **字号提档**：正文/按钮/等宽 12.5→13.5、小字 10→11.5。小号中文笔画在灰度抗锯齿下被稀释，字号是比颜色更有效的杠杆。
- **设置窗文字**：表单标签与示例提示改主文字色；浅色主题次级文字色压深一档（#6b6b76→#55555f）。

## 🔎 OCR

- **识别质量**：tesseract 输入预处理（灰度化 + 透明底合成白底）；语言包缺失在启动检查阶段给出明确安装提示（`tesseract-ocr-chi-sim` 等），不再静默回退到仅支持拉丁字母的内置 ocrs 产出乱码；GUI 固定请求 `chi_sim+eng`；内置 ocrs 不再误删合法单字符结果。
- **结果窗口**：预览/标注模式下改为独立系统窗口，可拖出截图框（内部浮层物理上出不了宿主窗口）；文本展示 + 右下角统一复制按钮，Esc 或 ✕ 即关即生效。

## 📌 贴图

- **编辑按钮**：工具栏新增 Logo 式「返回编辑」（圆角方框 + 铅笔），在完整标注窗打开当前贴图（可标注/OCR/重新贴图），成功后关闭原贴图；启动失败保留原贴图。
- **空格 = 复制并关闭**：一键交付；Ctrl+C / 双击保持仅复制不关窗。
- **拖动修复**：Wayland 下拖动一次后底部按钮全部点不了的根因是整窗注册为拖拽响应区、合成器吞松开事件后按钮点击被当成继续移动——现拖动只绑定图片区，X11 穿透形状在拖动后强制重发。
- 滚轮缩放不再把窗口宽度压到工具栏最小宽度以下。

## 🖼️ 界面与 Wayland

- **自绘标题栏**：设置窗 / OCR 结果窗口在 Wayland 下弃用 winit libdecor 兜底装饰（灰底方块按钮与主题脱节），改主题化自绘标题栏（拖动 + 最小化/最大化/关闭，浅夜两主题跟随），标注窗标题栏按钮几何与全应用统一。
- **标注窗工具栏**：Wayland 初始/最小宽度提至 800，停靠工具栏单/双行动态高度，窄窗口下保存/贴图/复制等交付按钮不再被裁出窗口。
- **覆盖层**：标注图元可移出选区显示与编辑（最终交付仍按选区裁剪）；选区角/边手柄命中区扩到图片外沿；预览/滚动截图模式选区支持角点与单边调整。
- **快捷键**：截图覆盖层空格 = 复制交付（与 Enter 同语义）；录屏/滚动截图调整阶段空格 = 确认交付。
- **设置窗**：夜间模式卡片补齐「抬起一层」的填充色与边框层次。

## 🛠️ 修复

- Wayland 全局热键注册加 8 秒超时并自动重试一次，portal 卡死不再导致热键静默失效（托盘菜单仍可用）。
- OCR/二维码结果窗口 ✕ 关闭立即生效（此前要等宿主窗口重绘）。
- 文档：README 标记 Wayland 支持并新增能力明细表（portal / slurp+grim 选路、剪贴板双写、热键与录屏边界）。
