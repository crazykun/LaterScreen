本版本经 macOS 真机点验，交付两块重点：macOS 录屏音频（系统声内录 +
一串盲写缺陷修复）与滚动截图的全面修复加固（mac 交互路径修复 + 三平台
拼接引擎重写）。

## 新功能（macOS 录屏音频，真机点验）

- **系统声内录落地（ScreenCaptureKit，macOS 13+）**：`--audio system|both`
  不再降级为麦克风，系统声音与麦克风同轨饱和混音；macOS 12 及以下自动
  降级并提示。首次使用需在系统弹窗授权「屏幕录制」与「麦克风」。
- 修复 v0.10.x macOS 音频路径的三批盲写缺陷：录屏第一帧整段挂死
  （事件源查询触发系统死锁，含降级方案）、AudioBufferList 变长结构越界
  （崩溃级）、启动就绪信号丢失与爆音（交错流字节序/声道布局处理）。

## 修复（滚动截图，mac 真机点验 ×9 + 拼接引擎 v2）

mac 交互框选路径此前**必然失败**（回退普通截图），本次逐项修复：

- 状态窗居中盖住选区中心，指针移过去后滚轮事件全被它吃掉 → 状态窗
  自动摆到选区外（不与选区重叠的一侧）。
- 滚轮改像素单位并按「自然滚动」设置校正方向；行单位被浏览器放大
  数十倍，内容整窗滚飞。
- 每步滚动量自适应：首步实测实际位移，按选区高度预算自动定档
  （浏览器对合成滚轮有加速放大），矮选区不再因一步滚过头而失败。
- 框选后可先把窗口摆好、滚到目标位置，点「开始滚动」后再自动滚
  （此前框完立即自动滚）；开拍前自动等你的惯性滚动停稳。
- 等待平滑滚动动画收尾后再取帧，消除长图重影/断段；录制红条与选区
  脱开 6px，不再被取整误差扫进画面（长图上的周期红线）。
- 失败时按成因给可行动提示（画面没动 / 选区底部压着固定内容 /
  选区太矮），并保底输出普通截图而非一无所获；`LSCREEN_SCROLL_DEBUG=1`
  可看逐步跟踪。

**拼接引擎 v2 重写（三平台）**：从「尾部块匹配」升级为「位移估计 + 全幅
验证」——文字稀疏的页面（聊天记录、代码 diff 等大量留白内容）此前基本
拼不上，现在可稳定拼接；纯色页脚/粘性底栏不再被重复拼入长图；亚像素
滚动的文字边缘抗锯齿漂移不再导致误判。

## 修复（其他）

- **贴图工具栏崩溃**（v0.10.0 起，Windows/mac 未配置上传命令的机器贴图
  必崩）：工具栏项缺位时不再 panic。
- **macOS 裸 F 键热键盲区提醒**：macOS 默认把 F1–F12 用作媒体键，裸 F 键
  热键注册成功但永远不触发；配置面板与托盘日志现在会明确提示原因与
  解法（系统设置▸键盘▸「将 F1、F2 等键用作标准功能键」，或改用组合键）。

## 已知事项

- 滚动截图选区底部压着固定输入条/工具栏时无法推进（有归因提示），
  把选区底边落在会滚动的内容上即可。
- macOS 系统声在桌面完全无声时可能不产生音轨，结束时会提示
  「未采集到音频数据」；有声音播放即正常。
- 真机验证套件新增滚动两帧探针与裸 F 键点验项，见 `docs/VERIFY.md`。
