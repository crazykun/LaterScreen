本版本经 Windows 真机验证修复了 v0.10.0 录屏音频的三处缺陷——v0.10.0
的 Windows 录屏音频实际不可用，本版恢复，并交付真机验证套件第一批。

## 修复（Windows 录屏音频，真机点验 M14 盲写路径）

- 修复启动音频采集必然超时（约 5 秒后报「音频设备无响应」）：就绪
  信号在采集线程退出时才发出，启动等待永远等不到。
- 修复 AAC 编码器初始化失败（`0xC00D36B4`）：码率参数单位应为
  字节/秒，128kbps 被写成 1Mbps，超出系统编码器支持范围。
- 修复编码线程缺少 COM 初始化（Media Foundation 的前置要求）。

## 新增

- 真机验证套件第一批（操作手册 `docs/VERIFY.md`）：窗口枚举 Z 序 +
  全屏截屏、系统 OCR 中英文、录屏音频麦克风/系统声的 env 门控端到端
  测试（`LSCREEN_TEST_E2E=1` / `LSCREEN_TEST_AUDIO=1`），真机可脚本化
  复跑。

## 已知行为

- Windows 系统声内录（loopback）在桌面完全无声时不产生音轨，录制
  结束时会提示「未采集到音频数据」；有声音播放即正常。

Windows 真机验证记录：OCR 中英文数字全识别、窗口枚举 Z 序与截屏
正常、麦克风（44.1kHz 虚拟声卡，含重采样路径）与系统声录制 A/V
偏差 0.044s。
