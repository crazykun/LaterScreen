本版本横跨 0.10–0.12（上一个 GitHub Release 是 v0.9.0），主题是 **Linux Wayland 支持落地**（niri 26.04 双屏真机验证），叠加 0.10 / 0.11 的分享、标注与录屏增强。

## 🐧 Wayland 支持（Linux）

- **交互式截图自动选路**：KDE / GNOME 走合成器原生框选 portal；niri / sway 等无交互 portal 的合成器自动退 slurp+grim（wlr-screencopy，需安装 `grim` + `slurp`），无坐标换算问题。
- **整屏截图阶梯**：portal 优先、grim 全桌面拼接兜底；所有 portal 调用带守护超时，彻底修掉「portal 不回包导致按截图毫无反应」。
- **剪贴板双侧写入**：X11 侧 arboard 持有 + Wayland 侧 wl-copy，修 niri/sway 等的 XWayland 桥不回传导致「提示已复制、Wayland 应用粘出旧内容」（需 `wl-clipboard`）；复制按钮不再可能挂起（ack 加 5s 超时）。
- **中文字体可靠加载**：改经 `fc-list :lang=zh` 挑选真实覆盖中文的字体，修部分发行版 `fc-match` 返回无汉字字体导致标注文字全方块。
- **贴图 / 标注窗可拖动**：Wayland 下走合成器交互式移动；标注窗在平铺合成器（niri 等）自动浮动，工具栏顶部新增拖动条，宽度下限提升保证工具栏单行。
- **明确的能力边界**：录屏 / 滚动截图 / 区域录制仍需 X11（明确报错，不做半吊子）；全局热键依赖合成器 GlobalShortcuts，无实现时降级托盘菜单（可用桌面快捷键绑 `lscreen gui` 代偿）。

## ✨ 新功能（自 v0.9.0）

- **分享上传 hook**：`[upload]` 配外部命令，产物路径经 stdin 传入（无注入面），stdout 首行 URL 自动复制并记入历史，截图 / 贴图工具栏一键上传。
- **录屏音频三平台**：麦克风 / 系统声 / 混合可选——Linux arecord/parec + ffmpeg、Windows WASAPI + Media Foundation、macOS CoreAudio + ScreenCaptureKit（13+）；armed 预热 + 零点对齐。
- **录制点击高亮**：点击处扩散圆环入镜，配置可关。
- **标注增强**：记忆上次选区（布局变化自动作废）、延时截图、文字标注背景色、取色历史（最近 8 色）、工具栏内生成二维码。
- **历史面板与单例**：截图 / 贴图 / 录屏缩略图统一管理；托盘 / 配置窗 / 框选覆盖层单实例防叠层，贴图保持多开。
- **真机验证套件（M17）**：env 门控 e2e 测试与手册 `docs/VERIFY.md`。

## 🐛 修复（自 v0.9.0）

- 双击复制改为自维护判定（egui 内置 `double_clicked()` 第二击常被吞），选区外双击同样交付。
- 工具栏全图标常驻、永不收进二级菜单；窄窗折行保底不挤丢交付按钮。
- 配色令牌化：品牌红按主题分深浅、选中态红底红字、夜间模式输入框不可见等一批对比度问题修复。
- macOS：截图「往右切一屏」、托盘全局热键自上线起未生效、窗口枚举性能 513ms→3ms、滚动长图拼接引擎重写。
- Windows：托盘左键单击不再直接开始截图（三平台统一弹菜单）、贴图穿透被下层窗口盖住、录屏音频就绪信号时机。
