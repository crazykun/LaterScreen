本版本聚焦贴图（M12）：对齐 Snipaste 的核心贴图能力，并整理托盘菜单与修复夜间模式下的输入框显示问题。

## 新功能（贴图增强）

- **不透明度调节**：Shift + 滚轮在 20%–100% 间调整贴图不透明度，滚轮上=更不透明，toast 实时显示百分比。
- **点击穿透**：工具条「穿透」按钮让点击穿到下层窗口，贴图仅作参考层；Esc 退出（窗口仍持焦点时），失焦后经托盘菜单「贴图 → 关闭穿透」恢复。
- **旋转 / 翻转**：R 旋转 90°、H / V 水平 / 垂直翻转，纯像素置换无损可逆；复制与保存所见即所得（即变换后的画面）。
- **像素网格**：显示比例 ≥8x 时叠加中灰网格线，方便查看小图标与像素画；最大缩放从 4x 提升到 16x。
- **缩放控件**：工具条新增 `[− 100% +]` 组——百分比实时预览，点击百分比（或按 0）重置 100%，−/+ 按档位步进吸附（25/50/…/1600），连点无浮点误差；键盘 +/=/− 同步支持。
- 工具条图标按参考风格重绘（缩放 / 旋转 / 镜像 / 保存）。

## 托盘改进

- 贴图相关菜单收进「贴图 ▸」子菜单：**显示贴图 / 关闭穿透 / 关闭所有贴图**，主菜单恢复纯功能动作列表。

## 修复

- 修复夜间模式（深色主题）下设置面板输入框不可见：输入域底色提亮、补齐被吞掉的 1px 描边，聚焦时显示品牌色边框。
- 修复 Windows / macOS 托盘菜单「关闭穿透」「关闭所有贴图」点击无响应的问题。
- 修复 Windows / macOS 构建破损与 Windows 测试失败，CI 恢复绿色。
