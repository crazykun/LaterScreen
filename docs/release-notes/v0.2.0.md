本版本新增「贴图」功能、扩展 OCR 引擎覆盖，并系统性修复了双渲染路径一致性与一批边界问题。

## 新功能

**🖼 贴图（Pin to Screen）**
- 把截图选区钉在屏幕上，以独立进程常驻，可随手移动
- 底部常驻图标工具条，不再遮挡贴图内容；窄窗口自动兜底布局
- 支持置顶切换、缩放（锚点手势内定格消抖）、内缩圆角描边高亮
- 右键菜单收敛为与截图覆盖层同风格的底部工具条

**🔍 OCR 引擎扩展**
- 新增 Windows（系统 OCR）与 macOS（Vision）原生引擎支持
- 内置 `ocrs` 纯 Rust 引擎作零依赖兜底，未装 tesseract 时仍可用

**📦 Windows 自绘安装器**
- 以自绘安装器（egui）替换 NSIS，per-user 安装（`%LOCALAPPDATA%` + HKCU），无需管理员权限、不弹 UAC

## 修复

- **双渲染路径一致性**：橡皮擦形状（方形盖章）、椭圆描边（外扩对齐 egui）、Line/Curve/箭头端帽（平头）、矩形拐角（尖角）、马赛克命中区（覆盖完整可见外沿）逐一对齐交互层与导出层
- 文本编辑中点击工具栏导出不再静默丢弃输入
- 尺寸输入框聚焦时不再被全局快捷键劫持（Enter/Esc/Backspace/Delete）
- 双击复制时 Curve/Mosaic/Eraser 不再残留第一击的单点笔迹
- GIF 默认保存路径防覆盖检查针对最终扩展名，不再失效
- 录屏编码尾盘落盘失败（ENOSPC/EIO）不再被静默吞掉，失败会清理半成品文件
- 修复 `env::args()` 遇到非 UTF-8 参数时的 panic
- 拉丁字符预览与导出统一使用同一主字体
