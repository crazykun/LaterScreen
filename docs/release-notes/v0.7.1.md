本版本无新功能，是一轮健壮性修复与工程加固：修一处 OCR 子进程可能互等卡死的隐患、截图历史并发写入可能丢一条、Windows/macOS 托盘创建失败不再崩掉常驻进程。

## 修复

**OCR（Linux）：文字密集的截图可能卡死**

识别结果走 stdout 管道回传，此前应用先把整张图写完 tesseract 的输入管道才开始收结果。日常截图的识别输出只有几 KB，从未暴露；一旦输出超过管道缓冲上限（约 64KB，满屏密集文字会超过），tesseract 阻塞在写结果、不再读输入，应用卡在写输入——双方互等。现在图像写入与结果读取并行进行，互等不可能再发生。

**截图历史：并发写入可能丢一条**

历史索引（index.toml）原先直接覆盖写，保存截图与历史面板刷新恰好同时发生时，面板可能读到半截文件——解析失败按空处理，刚截的图就没进历史。现在改为写临时文件后原子替换，读到的永远是完整的新版或旧版。

**Windows/macOS：托盘创建失败不再崩掉常驻进程**

托盘图标创建失败此前会直接崩溃退出，常驻进程连同全局热键一起消失，且后台程序的崩溃信息用户根本看不到。现在降级为「仅热键」常驻并记录告警。正常环境几乎不会触发，属于极端环境兜底。

## 工程

- 截图历史与图片导出两个模块补齐单元测试（索引管理、单实例锁、区域裁剪边界、时间换算、防覆盖等，+32 个用例），测试不再依赖运行机器上的用户配置
- CI 新增 cargo audit 供应链扫描（RUSTSEC 安全公告，每周定时 + 每次提交；当前依赖无已知漏洞）
