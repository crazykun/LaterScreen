本版本聚焦截图体验（M13）与录屏增强（M14：点击高亮 + 三平台音频），并带来分享集成（M15：可插拔上传 hook）。

## 新功能（截图，M13）

- **记忆上次选区**：再次进入截图覆盖层时自动框选上次交付（复制/保存/贴图/OCR）的区域；显示器布局变化后自动作废回退，不会框到不存在的屏。
- **延时截图**：`lscreen gui --delay 3` / `shot --delay 3` 延时数秒后截图；托盘菜单与全局热键同样支持，倒计时状态可见。
- **文字标注背景色**：文字工具可为文本加背景色块，压在复杂画面上仍清晰可读（默认无背景，与旧版一致）。
- **取色历史**：取色器与 OCR 前的取色共享最近若干次颜色记录，重复取色不必来回切换。
- **二维码生成**：覆盖层工具栏可把输入文本生成二维码贴入标注（识别能力之外的生成方向补齐）。

## 新功能（录屏，M14）

- **点击高亮**：录制时鼠标按下处叠加扩散圆环（300ms 淡出），教程录制一眼看清操作位置；GIF/MP4 均生效，配置面板可关。
- **录屏音频（MP4）**：`record --mp4 --audio mic|system|both|off`，缺省读配置面板新增的「录制音频」选项（armed 等待期也能经状态窗齿轮热改，对本次录制生效）。
  - **Linux**：子进程链（arecord/parec 采集 + ffmpeg 编码），需系统装有对应工具，缺失时开录前明确报错；`both` 为双源饱和混音单音轨。
  - **Windows**：WASAPI 采集 + Media Foundation AAC，系统 API 直采，无需安装任何工具。
  - **macOS**：支持麦克风（CoreAudio + AudioToolbox AAC）；系统声内录暂不支持（待 ScreenCaptureKit），配置为 system/both 时自动降级为麦克风并提示。
  - 三平台同一对齐语义：armed 预热 + 录制零点对齐（起流晚到补静音），音轨时间 0 恒对齐视频时间 0；采集/编码故障只告警不毁视频。
  - 注：Windows/macOS 音频为本版新实现的系统 API 路径，已通过三平台 CI 编译与单元测试，真机表现欢迎反馈。

## 新功能（分享，M15）

- **上传 hook**：`config.toml` 配 `[upload] command = [...]` 后，把任意外部命令变成图床入口（uPic/PicGo/sup 或自写脚本均可）：产物**路径**经 stdin 传递（不经 shell、无注入面），stdout 第一个非空行视为 URL，自动复制到剪贴板并记入历史；命令挂死 30 秒自动终止。配置后覆盖层工具栏与贴图工具条出现「上传」按钮，`lscreen upload <file>` 为脚本化入口。

## 改进与修复

- 设置面板表单控件高度统一（输入框与下拉框/数字框同源等高）。
- 修复 Windows/macOS 托盘菜单缺少「延时截图」项（非穷尽分支在 Linux 之外的平台被 cfg 掉，CI 矩阵才暴露）。

## 已知事项

- macOS 系统声内录待 ScreenCaptureKit 支持（当前自动降级麦克风）。
- Wayland 下区域采帧/录屏仍需 X11（整屏截图与 portal 交互可用）。
